# sunxichen's blog

Hugo + [PaperMod](https://github.com/adityatelange/hugo-PaperMod), deployed to GitHub Pages by `.github/workflows/hugo.yaml`.

```bash
git clone --recurse-submodules https://github.com/sunxichen/sunxichen.github.io.git
hugo server -D            # preview at http://localhost:1313
hugo new content posts/xxx.md
```

Each post uses `categories` for the project and `tags` for topics.
